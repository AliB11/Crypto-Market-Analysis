# بازبینی پیش از انتشار — لانگ و شورت

تاریخ: ۲۰۲۶-۰۹-۱۶  
شاخه: `arena/01a0a8b2-crypto-market-analysis`

## نتیجه

**برای پوش و انتشار به‌عنوان نسخه تحلیلی/آزمایشی، پس از اصلاحات این بازبینی، مانع شناخته‌شده‌ای در سناریوهای آزموده‌شده باقی نمانده است.** این نتیجه تأیید سودآوری، کیفیت اجرای سفارش یا آمادگی برای معامله واقعی/اهرم‌دار نیست. هیچ commit یا push در این بازبینی انجام نشده است.

دامنه بررسی: موتور تحلیل و Worker، پلن مستقل شورت، رژیم و دروازه‌ها، تداخل با لانگ، تازگی داده و مسیر خطا/کش، چرخه کارنامه، ذخیره‌سازی، فیلتر اعلان‌ها، محاسبه حجم، مودال/نمودار، CSV و Service Worker.

## آزمون‌های اجراشده

### خودکار بدون مرورگر

```bash
node --check app.js
node --check short-engine.js
node --check indicator-worker.js
node --check sw.js
node tests/gate.test.mjs
node tests/quality.test.mjs
node --test tests/short.test.mjs
git diff --check
```

- **۲۱ تست یکپارچه‌سازی موفق**؛ شامل تست‌های موجود و رگرسیون‌های این بازبینی.
- **۱۸ تست موتور شورت موفق**؛ شامل هندسه روی ۳۰۰ مقیاس قیمت، چرخه انتظار/ورود/خروج، ورودی نامعتبر و بازیابی تاریخچه.
- مجموعه بررسی کیفیت، امنیت ساختاری، کش و Worker موفق.
- برابری اندیکاتورهای Worker و thread اصلی روی ورودی آلوده نیز بررسی شد.
- بررسی syntax و whitespace بدون خطا.

### مرورگر واقعی

فایل قابل تکرار: `tests/browser.smoke.mjs`.

با Chromium واقعی، CSP برنامه فعال و بدون فعال‌کردن `unsafe-eval`:

1. **عرض ۱۲۸۰:** بارگذاری تحلیل با Worker، پنل شورت، ثبت انتظار، مودال، نمودار، حجم، CSV، هشدار، فعال‌شدن معامله، حفظ سطوح پس از reload و توقف روی قطع API.
2. **عرض ۳۹۰:** همان زنجیره؛ بدون overflow افقی کل صفحه.
3. **Service Worker:** نصب پوسته آنلاین، قطع کامل شبکه و reload آفلاین؛ موتور و صفحه همچنان در دسترس و بدون خطای JavaScript.

**هر سه سناریو موفق بودند و خطای `pageerror` ثبت نشد.**

پاسخ‌های بازار برای دو سناریوی اول deterministic و ساختگی هستند؛ ابتدا مسیر واقعی دریافت → Worker → analyze → زمینه بازار → رندر اجرا می‌شود، سپس برای کنترل چرخه ورود، یک ستاپ شناخته‌شده تزریق می‌شود. این روش تست، تأیید اتصال پایدار CoinGecko یا نرخ تولید/موفقیت سیگنال در بازار زنده نیست.

## محدودیت‌ها و ریسک‌های باقی‌مانده

- داده قیمت sparkline است، نه OHLCV قرارداد صرافی. زمان دقیق نمونه‌های sparkline از زمان `last_updated` قیمت قابل استنتاج قطعی نیست؛ بنابراین تأیید کندل بسته‌شده یا اجرای دقیق پولبک ادعا نمی‌شود.
- امتیازها و آستانه‌ها تجربی‌اند. هیچ بک‌تست تاریخی، تست خارج از نمونه یا فورواردتست سودآوری در این بازبینی انجام نشده است.
- رژیم مشترک بازار هنوز مؤلفه‌های بازگشت‌محور نسخه لانگ را دارد؛ شورت علاوه بر آن به ساختار و مومنتوم نزولی مستقل نیاز دارد. آستانه‌های رژیم نیازمند کالیبراسیون با داده تاریخی‌اند.
- کارنامه، قیمت‌های مشاهده‌شده را ارزیابی می‌کند؛ برخورد هدف/حد ضرر بین دو نمونه ممکن است دیده نشود. مرورگر بسته/تعلیق‌شده یا دارایی خارج‌شده از فهرست ۱۰۰ ارز، پایش پیوسته ندارد.
- هدف اول یا حد ضرر یا سررسید ۷روزه رکورد را می‌بندد. هدف دوم نمایشی است؛ خروج پله‌ای اجرا نمی‌شود.
- امکان واقعی شورت، فاندینگ، کارمزد، اسپرد، لغزش، اهرم و لیکوییدیشن محاسبه نشده‌اند.
- ماشین‌حساب، ریسک یک معامله را نشان می‌دهد. محدودیت مجموع سرمایه یا همبستگی معاملات هم‌زمان و تخصیص سرمایه سبد پیاده نشده است.
- داده‌ کهنه همچنان برای مشاهده تحلیل قابل نمایش است، اما مجوز ثبت/ارزیابی کارنامه و رویداد تازه محسوب نمی‌شود.
- تاریخچه در localStorage همان مرورگر است؛ همگام‌سازی سرور، تضمین نگهداری پس از پاک‌کردن داده مرورگر و پشتیبان‌گیری خودکار ندارد.
