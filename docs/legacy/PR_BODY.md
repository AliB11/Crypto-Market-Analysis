# تب‌بندی لانگ/شورت/دوطرفه + خروجی ماشین‌خوان سیگنال‌ها + رفع چهار باگ

اجرای **گام ۱ و گام ۳** از سند `PROPOSALS.md` (که در همین PR اضافه شده)، دقیقاً در محدوده‌ی «بدون ریسک عملیاتی»: هیچ بک‌اند، لاگین، دامنه، Cloudflare، GitHub Actions یا کلید API‌ای اضافه نشده. سایت کاملاً استاتیک و رایگان باقی می‌ماند و نسخه‌ی GitHub Pages دست‌نخورده کار می‌کند.

> **موتور معاملاتی به‌هیچ‌وجه تغییر نکرده.** هیچ آستانه، وزن، امتیاز یا قاعده‌ی تصمیم‌گیری عوض نشده — جزئیات در بخش «تضمین عدم آسیب».

## ۱) گام ۱ — تب‌بندی جهت معامله

پیش‌تر سیگنال‌های لانگ و شورت در یک صفحه‌ی طولانی قاطی بودند. حالا سه تب واقعی با `role="tablist"` اضافه شده:

| تب | بخش‌های اختصاصی |
|---|---|
| 🟢 لانگ (پیش‌فرض) | `#bestSec` (بهترین‌های خرید)، `#perfSec` (کارنامه) |
| 🔻 شورت | `#shortSec` (میز کار شورت) |
| ⚖️ دوطرفه | `#dualSec` (نمای تطبیقی جدید) |

- بخش‌های زمینه‌ای (نمای کلی، نبض بازار، مقایسه، خروجی JSON، فهرست ارزها) در **هر سه تب** باقی می‌مانند.
- **نمای دوطرفه** قابلیت تازه‌ای است: هر ارز را با هر دو جهت کنار هم می‌گذارد و **تعارض** لانگ/شورت را برجسته می‌کند. منطق تعارض از قبل در موتور بود ولی هیچ‌وقت به کاربر نشان داده نمی‌شد.
- تب فعال در `localStorage` (کلید `cb_side_v1`) و در hash آدرس (`#long` / `#short` / `#both`) نگه داشته می‌شود؛ مقدار خراب یا ناشناخته با امنیت به لانگ برمی‌گردد.
- پیمایش کامل با صفحه‌کلید (جهت‌دارها با در نظر گرفتن RTL، Home/End) و شمارنده‌ی زنده‌ی تعداد سیگنال روی هر تب.
- **مهم:** پنهان بودن یک تب موتور آن را خاموش نمی‌کند. چرخه‌ی شورت و پایش در پس‌زمینه ادامه می‌دهد و tick در تب پنهان پلن‌ها را از نو نمی‌سازد — هر دو با آزمون پوشش داده شده‌اند.

## ۲) گام ۳ — خروجی ماشین‌خوان (`#apiSec`)

قرارداد **JSON نسخه‌دار (`schemaVersion: "1.0"`)** شامل تمام پارامترهای ورود، حد ضرر، دو هدف، پله‌های ورود، ریسک/بازده و دلیل رد شدن سیگنال‌ها.

- انتخاب جهت (لانگ/شورت/هردو) و فیلتر (فقط مجاز / همه با دلیل رد)، به‌همراه دکمه‌های کپی و دانلود.
- فیلد `dataAsOf` و پرچم `dataFresh` تا مقصد بتواند سیگنالِ روی داده‌ی کهنه را رد کند.
- استیبل‌کوین‌ها و توکن‌های رَپ‌شده هرگز وارد خروجی نمی‌شوند.
- **چرا کلید API ندارد:** تا وقتی بک‌اندی وجود ندارد، هر کلیدی در مرورگر قابل خواندن است و امنیت کاذب می‌سازد. این موضوع صریحاً در خود صفحه توضیح داده شده. این خروجی پایه‌ی یک API واقعی است، نه جایگزین آن.

## ۳) باگ‌هایی که رفع شد

1. **شاخص ترس و طمع کار نمی‌کرد** — `renderFNG()` هرگز صدا زده نمی‌شد و پنل روی placeholder می‌ماند. حالا رندر می‌شود، سرویس خراب «—» می‌دهد نه `NaN`، و در آن حالت گاردریل مربوطه غیرفعال می‌شود (نه اینکه با داده‌ی نامعتبر تصمیم بگیرد).
2. **فیلتر هشدار «فقط شورت»** پس از رفرش پاک می‌شد، چون `'short'` در فهرست اعتبارسنجی بارگذاری جا افتاده بود.
3. **کامنت نادرست** بالای بخش شورت (`Track record / backtest`) اصلاح شد.
4. **دسترس‌پذیری تب‌ها** (کامیت دوم): `aria-controls` به بخش‌هایی اشاره می‌کرد که `role="tabpanel"` نداشتند — برای صفحه‌خوان یک ارجاع شکسته. هر چهار بخش نقش `tabpanel` و `aria-labelledby` گرفتند و `tabLong` هر دو بخش خود را اعلام می‌کند.

همچنین نوار تب‌ها و بلوک خام JSON در `@media print` پنهان شدند، و نسخه‌ی کش Service Worker به `cryptobin-shell-v6` رسید (الزامی، چون فایل‌های shell عوض شده‌اند).

## آزمون‌ها

```bash
node tests/gate.test.mjs        # ۲۹/۲۹ ✅  (۱۱ آزمون قبلی + ۱۸ آزمون جدید تب/JSON)
node --test tests/short.test.mjs # ۱۸/۱۸ ✅
node tests/quality.test.mjs      # ✅  CSP، نسخه کش، قرارداد ARIA، نبود handler درون HTML
```

علاوه بر این، یک سوییت **۲۹ آزمونی end-to-end با jsdom** (DOM واقعی + cascade واقعی CSS + `getComputedStyle`) اجرا شد و همه سبز بود: بوت، ترس و طمع، ماتریس نمایش تب‌ها، استقلال موتور از تب، نمای دوطرفه، خروجی JSON، ماندگاری فیلترها، رگرسیون CSV/مودال/آفلاین و تزریق XSS.

یک **آزمون خاصیت‌محور** هم روی ۶۰ بازار تصادفی (قیمت‌های ۰٫۰۰۰۱ تا ۱٬۰۰۰٬۰۰۰ دلار) و ۹۶۰ سیگنال اجرا شد: ترتیب `stop < entry < tp1 < tp2` برای لانگ و معکوس آن برای شورت، مجموع وزن پله‌های ورود همیشه ۱۰۰، و ورود هرگز بالاتر از قیمت بازار — **صفر نقض، صفر `NaN`**.

هر سه باگ با برگرداندن موقت خطا راستی‌آزمایی شدند تا مطمئن شویم آزمون‌ها واقعاً شکست می‌خورند (آزمونِ بی‌اثر نباشند).

## محدودیت راستی‌آزمایی

- در محیط اجرا **مرورگر واقعی در دسترس نبود**، بنابراین `tests/browser.smoke.mjs` (Playwright) اجرا نشده باقی مانده است. jsdom جای خوبی را پر می‌کند ولی جایگزین بازدید انسانی نیست.
- **دسترسی شبکه‌ی خروجی بسته بود** (`http=000`)، پس پاسخ زنده‌ی CoinGecko و alternative.me آزموده نشد و همه‌ی آزمون‌ها روی fixture اجرا شدند.
